## 2026-07-23更新后的检索规则

- 首选时间窗口：最近30天。
- 扩展时间窗口：最近180天。
- 扩展触发：合格文献不足5篇、4临床加1基础构成不足，或优先期刊不足3篇。
- 扩展后仍优先近30天文献。
- 永久去重只使用正式`published`记录。
- `candidate`、`analyzed`、`validated`但未发布、`failed`及Demo记录不占用永久历史。
- 其余影响因子、评分和相关性条件继续生效。

## 已知维护事项

1. `config/journal-metrics.json`中的部分麻醉期刊使用可公开核验的较早年度影响因子；新版JIF发布后要人工复核。
2. 未加入影响因子配置的期刊会被严格排除，即使其真实影响因子可能大于5。
3. 本机Git远程当前使用SSH地址；如果本机没有对应SSH密钥，终端会出现`Permission denied (publickey)`。可使用已登录GitHub网页、配置GitHub CLI，或改为已认证的HTTPS方式。
4. GitHub Actions日志中的Node运行时弃用警告来自第三方Actions，不影响当前成功运行，但后续应在官方Actions发布新版时升级。
5. 真实中国移动、联通、电信和微信内置浏览器的完整网络验收仍需真实用户设备完成，不能由AI虚构通过。
6. `SITE_URL`尚无长期公开域名时，RSS中的站内详情链接只能作为本地/预览用途；这不影响Buttondown每日邮件。
7. 完整`npm audit`仍会报告构建期可选`sharp 0.34.5`及未启用的Drizzle示例工具链；截至审计日上游尚无`sharp 0.35.0`可安装。静态站点设置`images.unoptimized=true`，不接收用户图片且最终只部署`out/`，所以这些组件不进入公开运行时；后续有上游修复版本时再升级，禁止按npm错误建议强制降级Next.js。
